## Lo que construimos

Desarrollamos herramientas digitales que acompañan la gestión comercial e inmobiliaria: aplicaciones web, mapas e integraciones que acercan la información a quienes la necesitan.

| Aplicaciones | Integraciones | Información |
| :--- | :--- | :--- |
| Experiencias web enfocadas en tareas concretas. | Conexiones entre plataformas y procesos de negocio. | Herramientas para consultar, visualizar y trabajar con datos. |

## Proyectos públicos

### 🗺️ [Mapa de ventas](https://github.com/gy-global/zoho-sales-map)

Una herramienta de visualización geográfica para acompañar la gestión comercial de GarantíaYa.

### 📍 [Inmocionate](https://github.com/gy-global/inmocionate)

Aplicación de mapas y registro de visitantes para la experiencia de GarantíaYa en eventos.

## Tecnología con propósito

En nuestros proyectos públicos combinamos **JavaScript, React, Vite, Leaflet y Supabase** para crear interfaces y herramientas orientadas a necesidades reales.

Cada repositorio reúne su código y documentación. Consultá su README para conocer el alcance, los requisitos y la forma de ejecutarlo.
